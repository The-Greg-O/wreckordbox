# The three directions shown first

`shell-directions.html` is the page shown at the start of the session: the same playlist as a reskin of upstream (A), the same model redrawn (B), and a keyboard-first interface (C), each at 1280, 640 and 436 px wide. It is a publishable fragment; wrap it in an HTML document to open it locally. The DJ could not choose between them from the page alone; the chosen design came from the questions that followed and is closest to B, with C's emphasis on keys for frequent actions. See `../../README.md` for why A and C were rejected.
